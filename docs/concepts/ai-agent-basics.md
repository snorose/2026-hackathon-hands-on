# AI 에이전트 기본 개념

이번 실습에서 에이전트는 거창한 로봇이 아니라, 입력을 보고 필요한 도구를 순서대로 사용하는 흐름입니다.

| 개념 | 이번 실습에서의 예 |
| --- | --- |
| Trigger | 프론트 화면이 n8n Webhook을 호출합니다. |
| Tool use | n8n이 Upstage OCR과 Chat API를 호출합니다. |
| Decision | 텍스트 입력인지 파일 입력인지 구분합니다. |
| Response | 피드백과 OX 퀴즈를 화면에 돌려줍니다. |
